\section{Method}
Staring with these papers [citation needed] from earlier work by Odd Erik Gundersen, Thijs Snelleman and Peter Lawrence.
Almost all papers referenced by these were classed as "not assessed", "not relevant", "relevant" or "very relevant".
Categories of papers were created and modified for relevant papers along the way.
Cited papers from "Very relevant" papers were also assessed.

Papers that cite "Very relevant" papers were also assessed.

These factors were used to decide if a paper was "not relevant", "relevant" or "very relevant":
\itemize{
\item In which context was this paper cited? If the context is one of the categories, then it is relevant.
\item If the context is not relevant, then the cited paper is also not relevant. (e.g. a list of papers that form a dataset for auto reproducibility)
\item Was this paper only cited in the bibliography, and not the main text? Then it is not relevant.
\item Does the paper's abstract relate to any of the categories. Then it's relevant. If not, then not relevant.
\item Some papers are borderline. They are listed here [TODO: compile list]
}

\subsection{Categories}
\itemize{
    \item Terminology \newline Contributes by defining terminology related to reproducibility.
    \item Prepub reproducibility \newline Techniques that authors can use to make their research more reproducible.
    \item Validation \newline Contributes benchmarks or other validation techniques for automatic reproducibility.
    \item Agentic Science \newline AI systems that can conduct scientific tasks autonomously.
    \item Code Repair \newline Systems that automatically repair old code.
    \item Hypothesis Gen \newline Systems that generate scientific hypotheses.
    \item Automatic Software Engineering \newline Systems that can do software engineering tasks autonomously.
    \item Science-specialized LLM \newline LLMs that are fine-tuned to be better at science.
    \item Multi-Agent \newline AI systems which consist of multiple collaborating agents.
    \item Journal policy \newline Papers that describe policies at journals. Mostly related to reproducibility.
    \item Reproducibility survey \newline Papers that survey the reproducibility of a field.
    \item Other
}
